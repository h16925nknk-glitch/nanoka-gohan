# 七日ごはん

一人暮らし向けの、1週間夜ご飯プラン作成アプリです。

## 起動方法

```bash
npm install
npm run dev
```

ターミナルに表示されたURLをブラウザで開いてください。

## 現在入っている機能

- 1週間の予算入力
- 苦手な食材の入力
- 7日分の献立を自動作成
- 買い物チェックリスト
- 1食ごとの価格・カロリー・調理時間
- 外食との価格比較
- 5ステップ以内の作り方
- 侘しさを感じさせない、やさしい「今日のひとこと」
- スマホ対応
- 献立のローカル保存

## 次に追加できるもの

- OpenAI API接続
- Firebaseログイン・保存
- 実際の食品価格データ
- 栄養計算データベース
- 食材在庫の厳密な使い切り計算

- ホームから確認できる調味料一覧


## AI機能の設定

この版では、画面から `/api/plan` を呼び出し、OpenAIで7日分の献立を生成します。
APIキーをブラウザ側へ置かないため、Vercel Functionsを利用する構成です。

### ローカル画面だけ確認する場合

```bash
npm install
npm run dev
```

APIに接続できない場合は、自動的にお試し献立へ切り替わります。

### AIまで動かす場合

1. Vercelにプロジェクトを登録
2. VercelのEnvironment Variablesへ以下を追加
   - `OPENAI_API_KEY`
   - `OPENAI_MODEL`（任意）
3. Vercelへデプロイ

### 今回追加した機能

- よく行くスーパーの登録
- 買い物に行ける曜日の複数選択
- 買い物日ごとに分かれた買い物リスト
- AIによる予算別献立生成
- 食材使い切りをAIへ指示
- AI接続失敗時のローカル献立
